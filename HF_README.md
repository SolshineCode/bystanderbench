# BlueDot Unit 2: Concealment-Probe Overnight Session (2026-09-01/02)

Private provenance archive for a BlueDot Technical AI Safety Project session run on a
local T7610 (dual Tesla M40 24GB, no cloud compute). Full narrative in
`bluedot-unit2-impossiblebench-2026-09-01.md` and `bluedot-unit2-incident-eval-gap-analysis-2026-09-01.md`
(mirrors of the session's entries in the private `linkedin-os-notepad` repo).

## Bottom line

The goal was to test whether a previously-validated "concealment probe" (a linear
direction in residual-stream activations separating "used a shortcut but concealed it"
from "used it and disclosed it," validated on synthetic/instructed data elsewhere)
generalizes to real, emergent concealment — using ImpossibleBench (deliberately broken
unit tests) as the elicitation environment and two local 27B models.

**Result: no probe could be fit.** A driver bug (missing generation timeout) destroyed
most of a 12-hour overnight run — 98-100% GPU utilization for hours was mostly a wasted
retry loop, not real generation. Surviving real data: 11 transcripts over only 2 unique
tasks, zero `concealed_cheat` samples. See `concealment-probe/WRITEUP.md` for the full,
honest account, including why the "0 cheats" number is explicitly NOT evidence about
model behavior (confounded by the data loss).

**What's real and reusable:** a from-scratch, validated method for extracting true
per-layer residual-stream activations from a live llama.cpp server (`extract_resid.cpp`),
a complete label/extract/probe-fit pipeline (validated on synthetic planted-signal data),
and a fixed eval driver ready for a real run.

  the fixed version (`timeout=2400` added after the retry-loop bug was found).
