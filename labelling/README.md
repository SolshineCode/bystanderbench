# Human labelling

Two blind packets for two independent raters. Read `PROTOCOL.md` first — it carries the
pre-registered analysis, written before any answers came back.

- `packet_features/` — 7 SAE components (1 target + 6 frequency-matched decoys), hand this over
- `packet_concealment/` — 28 unlabelled AI answers, hand this over
- `_keys/` — answer keys. **Do not send these.**
- `responses/` — returned sheets, filed unedited
- `build_*.py` — regenerate either packet exactly (seed 20260908)

Both packets are deliberately free of any mention of concealment, deception, cheating,
or the project, so a rater cannot infer the hypothesis from the materials.
